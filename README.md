E-Learning adalah metode pembelajaran modern berbasis teknologi digital yang memungkinkan siswa belajar secara daring tanpa batasan ruang dan waktu. Aplikasi E-Learning Hybrid ini dikembangkan menggunakan React Native sehingga dapat berjalan lintas platform (Android dan iOS) dengan antarmuka mobile-first yang responsif. Aplikasi ini dilengkapi fitur manajemen materi, video conference, forum diskusi, kuis otomatis, dan notifikasi pembelajaran. Pengajar dan siswa memiliki dashboard sesuai peran masing-masing untuk mengelola dan mengakses materi serta evaluasi belajar secara real-time (Arkorful & Abaidoo, 2015). Aplikasi ini juga mendukung konsep blended learning, menjadikannya solusi fleksibel untuk pendidikan masa kini, terutama di era pascapandemi.

Fitur fitur yang ada di aplikasi ini berupa :
1. Halaman Register
2. Halaman Login
3. Halaman Forgot Password
4. Halaman Utama
5. Halaman Course
6. Halaman My Learning
7. Halaman Profile
8. Course Dashboard
